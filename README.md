# Kanki TDM

یه بازی تیم‌دث‌مچ (TDM) سوم‌شخص، شبیه حالت TDM پابجی موبایل، برای بازی با دوستان روی سرور خودمون.

- **۵ نفر در برابر ۵ نفر** (حداکثر ۱۰ بازیکن)
- برنده: تیمی که زودتر به **۴۰ کیل** برسه، یا وقتی **۱۰ دقیقه** تموم شد جلوتر باشه
- بعد از مرگ، **۳ ثانیه** بعد دوباره زنده می‌شی
- تیر به سر (Headshot) دو برابر دمیج داره
- دکمه‌های صفحه رو می‌تونی **جابه‌جا و بزرگ/کوچیک** کنی (مثل پابجی)
- حساسیت (Sensitivity) دوربین و اسکوپ قابل تنظیمه

ساخته‌شده با موتور [Godot 4.3](https://godotengine.org) — رایگان و بدون مشکل تحریم.

---

## گرفتن فایل‌های بازی (APK و EXE)

با هر تغییر کد، GitHub خودش بازی رو می‌سازه:

1. توی صفحهٔ ریپازیتوری برو به تب **Actions**
2. آخرین اجرای سبز (✓) با اسم **Build game** رو باز کن
3. پایین صفحه، قسمت **Artifacts**:
   - `KankiTDM-android` → فایل APK برای گوشی
   - `KankiTDM-windows` → فایل EXE برای کامپیوتر
   - `KankiTDM-server` → سرور برای VPS

> روی گوشی موقع نصب APK باید «نصب از منابع ناشناخته» رو اجازه بدی.

## راه‌اندازی سرور روی VPS

VPS پیشنهادی برای ۱۰ نفر: **۲ هسته CPU، ۲ گیگ RAM**، اوبونتو ۲۲.۰۴ یا ۲۴.۰۴.

1. `KankiTDM-server` رو از Actions دانلود و از حالت zip خارج کن
2. پوشه رو با WinSCP (یا `scp`) روی VPS آپلود کن
3. روی VPS داخل همون پوشه بزن:
   ```bash
   sudo bash install-server.sh
   ```
4. تمام! سرور روی پورت **UDP 7777** اجرا می‌شه و بعد از ری‌استارت VPS هم خودش بالا میاد.

دستورهای مفید:
```bash
journalctl -u kanki-tdm -f        # دیدن لاگ زنده (کی وارد شد، کی کی رو کشت)
sudo systemctl restart kanki-tdm  # ری‌استارت سرور
sudo systemctl stop kanki-tdm     # خاموش کردن سرور
```

> اگه شرکت VPS فایروال جدا داره (توی پنل سایتش)، پورت **7777 UDP** رو اونجا هم باز کن.

## بازی کردن

توی منوی اول اسمت و **IP سرور** رو بنویس و **JOIN MATCH** رو بزن.

| کار | گوشی | کامپیوتر |
|---|---|---|
| حرکت | جوی‌استیک چپ | W A S D |
| چرخوندن دوربین | کشیدن انگشت سمت راست صفحه | موس (اول یه بار کلیک کن) |
| شلیک | دکمهٔ FIRE (دو تا هست: چپ و راست) | کلیک چپ |
| اسکوپ (Aim) | دکمهٔ AIM | نگه داشتن کلیک راست |
| پرش | JUMP | Space |
| نشستن | CROUCH | C |
| خشاب | RELOAD | R |
| جدول امتیاز | دکمهٔ SCORE | نگه داشتن Tab |
| آزاد کردن موس | — | Esc |

**جابه‌جا کردن دکمه‌ها:** منوی اول ← **CONTROLS** (یا وسط بازی: MENU ← EDIT CONTROLS). دکمه رو بکش، با اسلایدر Size اندازه‌اش رو عوض کن، بعد **SAVE**.

## اجرا روی کامپیوتر برای تست و توسعه

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) رو دانلود کن (نسخهٔ Standard، نه .NET)
2. توی Godot: **Import** ← فایل `project.godot` همین پوشه رو انتخاب کن
3. کلید **F5** رو بزن تا بازی اجرا بشه
4. برای تست بدون سرور: توی منو **HOST (LAN)** رو بزن. بقیه روی همون وای‌فای می‌تونن با IP کامپیوترت وصل بشن.

گزینه‌های خط فرمان (برای تست، بعد از `--` بنویس):

| گزینه | کار |
|---|---|
| `--server` | اجرا به‌عنوان سرور (با `--headless` خودش سرور می‌شه) |
| `--port=7777` | پورت سرور |
| `--join=1.2.3.4 --name=Ali` | مستقیم وصل شدن به سرور |
| `--bot` | بازیکن خودش بازی می‌کنه (برای تست سرور) |
| `--touch` | نشون دادن کنترل‌های لمسی روی کامپیوتر |

## ساختار پروژه

```
autoload/settings.gd       تنظیمات ذخیره‌شده (اسم، IP، حساسیت، چیدمان دکمه‌ها)
autoload/network.gd        اتصال: سرور / کلاینت / هاست
scripts/main_menu.gd       منوی اول
scripts/game.gd            قوانین مسابقه: تیم‌ها، امتیاز، تایمر، برنده
scripts/player.gd          سرباز: حرکت، دوربین، شلیک، دمیج، مرگ و زنده شدن
scripts/map_builder.gd     ساخت مپ «انبار» (Warehouse)
scripts/fx.gd              افکت تیر و صدای شلیک
scripts/hud/               صفحهٔ بازی، دکمه‌های لمسی و ویرایشگر چیدمان
scripts/ui/                ظاهر منوها و پنجرهٔ تنظیمات
server/                    اسکریپت نصب سرور روی VPS
```
